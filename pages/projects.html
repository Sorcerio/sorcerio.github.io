The Web4 Website

Godot 4 Blender 4 WASM JavaScript Python CSS HTML

This website is a realistic take on the Web4 experience; an immersive 3D web environment inspired by the early Cyberpunk genre. Built with Godot 4.3, the project leverages WASM to deliver a fully functional HTML and CSS website inside a 3D world. Featuring custom models, interactive elements, and a retro aesthetic, it demonstrates how far the browser can be pushed when you refuse to stay inside the box.

The LLM Adventure Game Framework

Godot 4 Python 3 AI Game Development

The LLM Adventure Game Framework (LAG) is an infinite text adventure game framework that uses AI to deliver unmatched gameplay flexibility and player agency, built with Python 3 and Godot 4. By leveraging both Large Language Models and Image Generation Models, the framework responds to open-ended player input with unique, contextually relevant text and visuals which creates a truly personalized gaming experience in the spirit of late-era text adventures.

This code is not available to the public, but a demo video is available.

PicoNote

Rust Open Source

PicoNote is a super lightweight Markdown notepad built in Rust to replace the now bloated "Notepad" applications shipped with modern operating systems. It delivers exceptional startup times, Markdown highlighting, and a ~5MB binary size across Windows and macOS.

Trippy Hike

iOS Swift GameKit StoreKit Game Development

Trippy Hike is a casual mobile game designed, developed, and shipped entirely by yours truly in the era before AI assistance. It implements native libraries including GameKit, GameCenter, and StoreKit to deliver an expandable and monetized experience from concept to App Store.

ArgUI

Python 3 Utility Open Source

ArgUI is an automatic, terminal-based interactive interface (TUI) for any Python 3 "argparse" command line, complete with keyboard and mouse support. It takes the now ubiquitous CLI and makes it accessible to anyone. No manual required.
