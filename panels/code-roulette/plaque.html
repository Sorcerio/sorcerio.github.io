Code Roulette

Exhibit · Python 3 · Game · Open Source
game multiplayer python russian-roulette terminal terminal-game tui

Code Roulette is a terminal interface based (TUI), online multiplayer, Russian Roulette game where the loser executes the winner's Python payload file.

The project started as a way to exercise my skills with multiplayer connectivity in a simple game environment. Later, after a conversation on the principles of the system, an idea came across the table: what if the program executed code if you lost? Taking this in stride, I put together the program as it exists today.

To play, users connect to a lobby complete with chat and wait for the host to start the game. Once started, each player must select a payload file that will be executed by the opposing player if they lose. Then, before the game begins, each player is shown the code that the other has selected. This allows for each player to review the code that might execute on their system so the wager is an informed one. Once both players accept the terms, the game begins and functions as standard. Then, when a player loses, the code is executed in real time on their machine broadcasting the terminal output to both players.
