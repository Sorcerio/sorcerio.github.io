PicoNote

Exhibit · Rust · Utilities · Open Source
Rust Open Source

PicoNote is a super lightweight Markdown notepad built in Rust. I built it to replace the now bloated "Notepad" applications shipped with modern operating systems with a goal to be as efficient as possible. It delivers exceptional startup times, Markdown highlighting, and a ~5MB binary size across Windows and macOS.
